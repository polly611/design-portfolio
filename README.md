# Lizzy · Selected Works

设计作品集的公开展示版，包含 11 个项目、12 个合作品牌 Logo 和项目展示图片。

本仓库为静态站点，可通过 GitHub Pages 发布。内容管理后台保留在原站点，仅供站点所有者使用。

## GitHub Pages

在仓库的 **Settings → Pages** 中将 **Build and deployment** 设为 **Deploy from a branch**，选择 **main** 分支和 **/(root)** 目录，保存后即可通过 GitHub Pages 访问。

项目详情使用 `#/project/…` 地址，兼容 GitHub Pages 的静态托管路径。
